Extending WP Cerber to the Edge

WP Cerber is a world-class detection engine, but it is bounded by your server's hardware limits. Our plugin bridges WP Cerber's local lockout intelligence with Cloudflare's edge network to form an impenetrable barrier.

1

WP Cerber Detects & Locks

A botnet attempts brute-force logins. WP Cerber Security detects the malicious activity and successfully locks out the IP address locally.

2

The Plugin Bridges the Event

The moment WP Cerber locks the IP, our plugin intercepts the event, sanitizes the IP address, and prepares the API payload.

3

Immediate Edge Sync

The plugin securely transmits the IP to your Cloudflare IP List. The block is applied across Cloudflare’s global edge locations within milliseconds.

4

Server Load Dropped to Zero

Subsequent requests from that blocked IP are discarded at the CDN level. They never reach your WordPress host, saving CPU and database resources.
